# 家計簿

自分用の家計簿。既存アプリの「分析が浅い」「つけても行動が変わらない」を解くために作る。

## 軸

**「いくら使ったか」ではなく「次に何をするか」が出る家計簿。**

## 画面

**入力** — 支出／収入、金額、カテゴリ、**満足度**、メモ、日付
**記録** — 日付ごとの一覧、CSVの取り込みと書き出し
**レポート** — 下記

## レポートの中身

- 収入 / 支出 / 収支
- **前の月との差、1年前の同じ月との差**
- **動かせるお金と、動かせないお金の切り分け**（固定費を別枠にする）
- **直近12ヶ月の支出グラフ**
- カテゴリ別（前月との差つき）
- **満足度の内訳**と、**金額が大きいのに「いまいち」だったもの**

## マネーフォワード ME との比較

| | MF | これ |
|---|---|---|
| 12ヶ月の推移 | 月540円 | 無料 |
| 支出内訳の前月比 | 月540円 | 無料 |
| CSV書き出し | 月540円 | 無料 |
| **満足度** | **なし** | **あり** |
| **動かせる／固定の切り分け** | **なし** | **あり** |
| 銀行・カードの自動連携 | あり | **なし**（個人に銀行APIが開放されていないため） |

## データの置き場所

**ブラウザの localStorage（端末の中だけ）。** サーバーには送られない。
端末を変えるとデータは引き継がれないので、移すときはCSVで書き出す。

## 動かし方

`index.html` をブラウザで開くだけ。ビルド不要、依存ライブラリなし。
