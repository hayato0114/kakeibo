# 家計簿

自分用の家計簿。既存アプリの「分析が浅い」「つけても行動が変わらない」を解くために作る。

## 軸

**「いくら使ったか」ではなく「次に何をするか」が出る家計簿。**

## いまできること（1週目）

- 金額・カテゴリ・**満足度**・メモ・日付を入れる
- 日付ごとにまとめて一覧表示
- 今月の合計
- 削除

## 予定

- 2週目 — 満足度の集計（**金額が大きいのに満足していない支出**）
- 3週目 — 月末のまとめ（動かせる支出だけを抜き出す）
- 4週目 — GitHub Pages で公開してスマホから使う

## データの置き場所

**ブラウザの localStorage（端末の中だけ）。** サーバーには送られない。
したがって端末を変えるとデータは引き継がれない。

## 動かし方

`index.html` をブラウザで開くだけ。ビルド不要、依存ライブラリなし。
